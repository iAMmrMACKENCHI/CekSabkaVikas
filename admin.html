⚙️ Apps Script Setup

  1. 1. Open Google Sheets → Extensions → Apps Script
  2. 2. Paste the Code.gs file provided in this project
  3. 3. Deploy → New Deployment → Web App
  4. 4. Execute as: Me | Who has access: Anyone
  5. 5. Copy the Web App URL
  6. 6. Paste it in script.js → APP_CONFIG.APPS_SCRIPT_URL
